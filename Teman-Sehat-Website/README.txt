# Website Teman Sehat

## Isi folder
- `index.html` — halaman login, beranda, dan seluruh isi menu.
- `css/style.css` — tampilan responsif untuk laptop dan ponsel.
- `js/app.js` — navigasi, login demo, penyimpanan refleksi, dan kuis interaktif.

## Cara memasang ke folder VS Code yang sudah ada
1. Ekstrak ZIP ini.
2. Salin `index.html`, folder `css`, dan folder `js` ke dalam folder proyek `teman-sehat-profesional`.
3. Izinkan penggantian file `index.html`, `css/style.css`, dan `js/app.js` jika Windows memintanya.
4. Pertahankan folder `assets` milikmu yang sudah ada (misalnya `logo.svg` dan `students.svg`).
5. Buka `index.html` dengan Live Server.

## Login demo
Isi username dan password masing-masing minimal 4 karakter. Ini hanya gerbang login tampilan di sisi browser, bukan autentikasi aman untuk data pribadi. Untuk login sungguhan diperlukan backend dan penyimpanan akun yang aman.
